🖨️ Sistema de Impresión Multiproceso

Sincronización de Procesos Concurrentes con Semáforos

📋 Descripción del Programa

Sistema de Gestión de Impresora Compartida

Este programa simula el acceso concurrente de múltiples usuarios a una única impresora compartida mediante procesos independientes que compiten por un recurso común. El sistema implementa exclusión mutua usando semáforos binarios para garantizar que solo un usuario pueda utilizar la impresora en cada momento, evitando conflictos y garantizando la integridad de los trabajos de impresión.

👤 Usuario

Proceso independiente que envía múltiples trabajos a la impresora. Adquiere el semáforo antes de imprimir y lo libera al terminar.

🖨️ Impresora

Proceso que simula una impresora física. En Java, gestiona una cola de trabajos; en Python, es representada por el acceso controlado.

🔒 Semáforo

Mecanismo de sincronización que controla el acceso exclusivo a la impresora. Solo permite un proceso a la vez en la sección crítica.

🎯 Gestor de Impresión

Coordina todos los procesos del sistema, inicializa el semáforo, lanza los usuarios y gestiona la finalización ordenada.

🔧 Tecnologías Implementadas: El proyecto utiliza programación concurrente con procesos reales (ProcessBuilder en Java, multiprocessing en Python), sincronización mediante semáforos binarios para exclusión mutua, y comunicación entre procesos a través de archivos (Java) o memoria compartida (Python).

💻 Implementaciones

☕ Implementación en Java

  • GestorImpresion.java: Clase principal que coordina el sistema
  • Usuario.java: Proceso que representa a cada trabajador
  • Impresora.java: Proceso que gestiona la cola de trabajos
  • Semáforo: Implementado mediante archivos (.lock)
  • Comunicación: Cola de trabajos en archivo de texto
  • Sincronización: Espera activa (polling) con createNewFile()

🐍 Implementación en Python

  • GestorImpresion: Clase coordinadora del sistema
  • proceso_usuario(): Función que representa cada trabajador
  • proceso_impresora(): Función informativa de la impresora
  • Semáforo: Objeto multiprocessing.Semaphore(1)
  • Comunicación: Semáforo compartido entre procesos
  • Sincronización: Bloqueo gestionado por el sistema operativo
🔑 Conceptos Clave: Exclusión Mutua - solo un proceso en la sección crítica; Semáforo Binario - valores 0 (ocupado) y 1 (disponible); Sección Crítica - código que accede al recurso compartido; Sincronización - coordinación entre procesos concurrentes.
